3 — the pairing in both scripts

Noto Serif Georgian for headings, FiraGO (Latin) with Noto Sans Georgian for body, UI and figures. The same homepage, live, in Georgian and English. Georgian runs longer in every string — the headline, the buttons and the product rows all hold.
